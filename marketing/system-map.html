4 · Who this is for — and what NOT to sell each size

Target size is honestly unknown, so the product is built to land anywhere on this ladder and grow rightward. The glow marks the beachhead bet.

Owner-operator 1–5 machines

One truck, a skid steer, a trailer of tools

  • Sell: theft watch + live map + tool tags. That's it — the $0-platform Track tier.
  • PDF snapshots for insurance claims.
  • Don't push: crews, time clock, QBO — noise at this size.

Small GC Beachhead

5–15 machines · 5–20 crew · the DCG mirror

  • Sell: Track + Operate — theft, scorecard ("who's using the truck"), time clock → payroll, QBO job-costing.
  • Every feature built so far serves this buyer first.
  • Don't push: API/exports, OEM fleet sync at volume.

Mid contractor 15–50 machines

Multiple crews, a real yard, maybe a PM

  • Sell: Run tier — AI assistant, digests, attribution, OEM telematics for the big iron, CAN on high-value machines.
  • Needs that appear here: multi-yard views, exports.
  • Don't build ahead: SSO, custom roles — wait for the pull.

Regional fleet 50+ machines

Unknown fit — Tenna's home turf

  • If they come: region rollups, role builder, SSO, contract billing get built then, funded by their check.
  • Do not chase yet: enterprise sales cycles would starve the beachhead.
